# Aidiel Ziat — Portfolio

Personal portfolio site for Aidiel Ziat, AI & Data Consultant at Deloitte SEA. Showcases work experience, education, projects, and skills across AI/ML, data engineering, and cloud architecture.

## Sections

- Hero introduction
- Work Experience
- Education
- Projects
- Certifications & Achievements
- Skills
- Contact

## Tech Stack

- **React** + **TypeScript**
- **Vite** - build tooling
- **Tailwind CSS** - styling
- **shadcn/ui** - component library
- **next-themes** - light/dark mode
- **Lucide React** - icons
- **React Router** - routing

## Development

```sh
# Install dependencies
npm install

# Start the development server
npm run dev

# Type-check
npx tsc --noEmit

# Lint
npm run lint

# Build for production
npm run build
```

## Deployment

Deployed via AWS Amplify, connected to the `main` branch of this repository. Pushing to `main` triggers a new build and deploy.
